# HTTP route inventory

Generated by `mondek api-spec`. Every retained JSON operation belongs to the unified `/api/v1` contract. The OpenAPI document endpoint is infrastructure and is excluded from its own operation catalog; `/api/docs`, `/health`, HTML and Git smart HTTP are separate transports.

Runner communication and operator workflows use the same experimental same-release policy. HTTP paths may change together with maintained callers; durable evidence and journal identities do not.
